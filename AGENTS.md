# Agent instructions

This repository is an agent playbook and native Home source kit. For a request to
set up this repository, start at AGENT-START.md and MASTERPROMPT.md. After reviewing
the local scripts, run `python3 agent.py start --json`; do not stop at a summary
or ask the owner to copy each command. Reuse existing facts and authorization.
Read COMPATIBILITY.md and RECOVERY.md before TV writes. A bare link by itself is
not permission to gain privilege, install on a TV, or change other devices.

"Use this" with the repo link means begin the local onboarding, not only summarize.
The target is native Home/dock/editing/direct Home return and optional local video.
Read WORKED-EXAMPLE.md. For a nonmatching device continue research and PORTING.md;
do not stop at the reference mismatch or invent a universal compatibility claim.
Read ACCESS-RESEARCH.md for persistent, hypothesis-driven access investigation.
Keep a private evidence/next-step ledger. Distinguish transport, argument, caller
permission and missing-path failures, and keep HiUtils and Fetcher results
separate. A missing exact guide or one rejected bridge must not end useful
authorized research. Pivot to the next source-backed route; never blindly repeat
an ambiguous write or treat a related-device report as this device's success.
Resume from established same-unit results. Classify structured response fields
separately from returned file text; never infer denial from a `permission` word
inside source. Scope `ENOENT` to the exact path/context, and retain incomplete
source as incomplete. Use the successful read contract before trying alternatives.

- Work only on an explicitly owned/authorized target. Respect watch-time pauses.
- Publishing/documentation tasks never authorize contacting or changing a TV.
- Preserve existing authorization; ask only for genuinely new access/scope.
- Finish concrete diagnostics and cleanup plans before asking for a new scope.
- A pending write/recovery dependency does not block independent source analysis.
- Match firmware and original-file hashes. Never edit a profile just to force a pass.
- Keep the existing OEM shell, parental checks, app authentication and updates.
- No network scanning, default passwords, permanent root listener or bootloader flash.
- No forced DNS changes to the whole household. Proposed rules are client-scoped.
- Keep private state in .private/; never publish generated OEM bundles, credentials,
  home-network identifiers, device logs, snapshots or personal media.
- Do not store passwords in source, commit messages, configuration examples or tests.
- Run node check.mjs, python3 check.py and python3 privacy-check.py before release.
- Also run `python3 agent.py simulate --json`, which includes assembled-bundle
  and agent safety-gate tests. Simulated success is not hardware validation.
- For simulation/documentation-only requests, never contact the TV, even read-only.
- Fill private device evidence from actual observations, never expected example values.
- Do not add a universal remote apply/root payload or a production fixture bypass.
- Use only official/pinned sources; no curl-to-shell and no unreviewed install scripts.
- Native Home tests require a rollback plan and a verified independent recovery path.
- Cancel/accept trial rollback before the owner resumes watching a film.
- Keep status honest: public packaging/media chooser offline-tested; paused Netflix
  automatic saver and real Home idle timeout unverified.
- No claims of universal compatibility, complete privacy or removal of streaming ads.
- Credit Libraries.dev/metal-fx, alvidaa and Free My TV; retain their licenses.
- Follow LICENSE-SCOPE.md: new original contributions are noncommercial;
  upstream and earlier MIT grants remain intact. Do not relicense third-party work.
