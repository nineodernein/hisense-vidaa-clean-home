# Security scope

Use only on a TV you own or have explicit permission to modify.
Unknown model, firmware hash, module path or recovery mechanism means stop.

The project does not ship root keys, prebuilt privileged packages, firmware images,
network scanners, bootloader flashes or automatic Netflix interception.
Do not expose a maintenance port publicly or leave a permanent root service.
Do not disable update/authentication services to preserve a modification.

The original native integration was tested on one device; this public packaging
is offline-tested. Treat model support and visual confirmation as separate facts.

If reporting a bug, redact device/account/network identifiers. Do not attach
full firmware, logs, environment files, process dumps or credentials.
Report a reproducible source-level issue; for a security vulnerability, use a
private GitHub report if available rather than publishing secrets in an issue.
